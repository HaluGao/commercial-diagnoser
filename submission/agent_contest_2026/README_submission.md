# 商业咨询智能体

面向商业建筑方案评审场景的多模态 Agent Demo。

## 1. 作品价值

商业咨询智能体用于解决商业建筑方案审看高度依赖个人经验、标准分散、反馈不成体系的问题。它聚焦购物中心、TOD 商业、商业街区及复合业态的前期方案评审，通过多模态输入和规则库组织能力，输出结构化、顾问式的审查意见。

本作品的核心价值包括：

- 将龙湖内部资料与商业设计判断依据沉淀成规则库，降低经验依赖。
- 支持 PDF、平面图、图片等多种输入形式，提升前期方案评审效率。
- 输出“错误指出意见 + 优化性意见 + 下一轮复核专题”的结构化结果，便于快速进入设计迭代。
- 将一次性审查升级为可沉淀、可复核、可演示的 Agent 工作流。

## 2. 作用原理

系统采用“本地预处理 + 外部多模态推理 + 本地规则组织”的混合架构。

工作流程如下：

1. 用户上传商业方案 PDF、平面图、图片或现场拍照材料。
2. 系统在本地完成文件预处理、文本抽取、图像整理和规则库加载。
3. 外部多模态模型对图纸和图片进行读图理解。
4. 结合内置规则库，生成顾问式结构化诊断结果。
5. 在网页端输出摘要与完整咨询报告，并支持 Markdown 下载。

当前规则基础主要包含两部分：

- `C2工具`
- `2024天街建标`

同时，系统已建立导入规则复核底库，作为正式规则库的扩充来源。

## 3. 使用平台

- 操作系统：macOS
- Demo 形态：本地 Streamlit Web 页面
- 外部接口：API易 多模态模型接口
- 输入格式：PDF、PNG、JPG、JPEG、WebP
- 输出形式：网页摘要、完整咨询报告、Markdown 报告下载

### 4.1 基础准备

- Python 3

### 4.3 使用步骤

1. 打开 Web 页面。
2. 在左侧 API 配置区填写 API易 Key。
3. 选择模型与规则范围。
4. 上传方案图纸、PDF 或拍照材料。
5. 点击“开始审查”。
6. 查看右侧摘要与完整咨询报告。
7. 下载 Markdown 报告作为审查成果。

### 4.4 常见问题

#### 问题 1：接口不可用

排查建议：

- 检查 API易 Key 是否有效。
- 检查模型白名单是否已包含当前模型。
- 优先使用兼容通道接入方式。

#### 问题 2：结果生成较慢

排查建议：

- 优先使用尺寸适中的测试材料。
- 检查网络连接和模型响应时间。
- 对复杂方案材料可以分轮次测试。

#### 问题 3：规则数量与预期不一致

说明：

- 当前支持正式规则库、复核底库与合并模式。
- 正式规则库与复核底库处于持续扩充与复核中。

## 6. 创新点

- 将商业建筑方案审看流程产品化为 Agent 工作流，而不是单次问答。
- 采用“本地预处理 + 多模态推理 + 规则库约束”的混合方案，兼顾效率与可解释性。
- 将内部标准资料转化为可持续扩充的规则资产，而不是一次性 prompt。
- 输出结果兼顾首屏摘要与完整报告，适合业务演示与后续复盘。
