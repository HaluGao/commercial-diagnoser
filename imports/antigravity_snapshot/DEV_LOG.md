# 商业建筑方案 AI 诊断器 (Commercial Architecture Scheme AI Diagnostic Tool)

> 本文档用于永久沉淀该项目的核心产品思路、架构设计与关键技术点。作为“文档即代码(Doc-as-Code)”的载体，可防范聊天记录丢失，并帮助任何接手的开发者（包括未来的 AI）瞬间恢复开发上下文。

## 1. 核心定位
本系统是一款专业级的智能审核终端，核心功能是将真实商业地产的“设计图面（图纸、PDF文件）”或“实拍现场（导视牌、施工环境）”与沉淀在本地的《建筑与商业内部规范库》进行严苛的结构化比对，自动输出体检报告。

## 2. 技术栈核心
*   **前端与交互底座**：`Streamlit`
*   **底层视觉引擎**：`Gemini 1.5 Flash` (首选) / Gemini Pro 系列。之所以锁定 Flash 是因为实测性能更强悍，且规避了 Pro 级模型容易被平台触发 `Quota Exceeded (429)` 的配额红线限制。
*   **文档解析组件**：`PyMuPDF (fitz)`，用于拆解多页高清晰度的 PDF 并转换为底层的机器视觉编码 (Base64 JPEG)。
*   **抗压限流与重试机制**：集成了 `requests` 的异常拦截与基于时序的指数退避自动重试，确保当并发拥堵时系统自动进入休眠冷却而不是直接崩溃。

## 3. 关键 UI 设计理念 (Stitch Vibe 视觉组)
放弃了 Streamlit 原生简陋的表单感，采用了深度定制的 CSS 注入进行界面重塑：
*   **Deep Dark 暗夜模式** (背景色 `#05050A`，配合极光动态渐变背景) 以展示这套体系的高级与严谨性。
*   **Glassmorphism 物理毛玻璃滤镜** 赋予全部操作面板现代悬浮感。
*   **全局发光与微动效交互**：流光按钮、无缝 Tab 切换动画组件。

## 4. 重点业务攻坚节点
### 4.1.  实现“现场走查”跨屏唤醒
**痛点**：传统产品只能在电脑前端上传 PDF，不符合商业运营团队线下“走查提问题”的场景。
**解法**：在代码库强注增设 `[ ] 手机外拍实景` 切换板块。利用 `st.camera_input` 支持跨平台的原生设备调用。项目只要挂在局域网上，员工手机访问 IP 即秒变硬件外拍终端，照片直穿 Gemini 后台数据库比对规范。

### 4.2.  知识结构化对齐引擎
**痛点**：AI 生成诊断报告由于大模型天生的散漫性，容易像聊天一样没有结构，不专业。
**解法**：在后台注入了**6大强行分类框架过滤算法**：
1. 商业动线与客流交通
2. 空间尺度与面积标准
3. 核心业态与铺位落位
4. 立面景观与设备消防
5. 商业价值与运营策略
6. 通用设计与综合规范
算法会在发送给大模型前先执行自动归类分发，并强制要求大模型按照【遵守/合规性评估】和【建设性优化建议】两种严密口径生成 Markdown 报告。

## 5. 本地衍生库依赖记录

